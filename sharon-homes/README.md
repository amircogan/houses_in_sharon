# בתים בשרון — אתר פרטי למעקב אחרי בתים להשכרה

אתר מותאם למחשב ולנייד (RTL) להצגת מודעות, גלילת כרטיסיות עם תמונות, מחיר, טקסט, קישור למקור, מועדפים, הערות והסתרה קבועה. אחסון SQLite. מותאם לבית פרטי בשכירות 15–25 אלף ש״ח, מתל מונד ודרומה.

## מה עובד ומה עדיין לא

**ממומש בקוד:** אתר, מאגר נתונים, יבוא של מודעות מ־JSON, מניעת כפילות לפי מקור ומזהה, עדכון מחיר ותיאור בלי לאבד הערות והסתרות, סריקה מתוזמנת מקבצי feed, והודעת דוא״ל יומית עם מספר התוספות של *אתמול* וקישור לאתר לשתי הכתובות המבוקשות.

**טרם מחובר:** איסוף אוטומטי ישיר מיד2/מדלן. כדי לסרוק אותם יש צורך בשיטת גישה מותרת ואמינה ומחבר מותאם למקור. אין התחזות/עקיפת חסימות. תצוגת תמונות מרוחקות תלויה בהרשאות הקישור והמקור. האתר אינו מפורסם בכתובת אינטרנט עד לפריסה.

## הרצה מקומית

Python 3.11+:

```bash
cd sharon-homes
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export APP_USER=homes
export APP_PASSWORD='choose-a-long-unique-password'
uvicorn app:app --host 127.0.0.1 --port 8000
```

פתיחה ב־http://127.0.0.1:8000; דפדפן יבקש שם משתמש וסיסמה. לבדיקה מקומית בלבד אפשר `ALLOW_LOCAL_NO_PASSWORD=1` בלי APP_PASSWORD. **לעולם לא להריץ כך ברשת ציבורית.**

## הוספת מודעות

צרו `feeds/authorized-export.json` (תבנית בקובץ `example-feed.json`) ממקור שהרשה זאת; אפשר גם לשלוח `POST /api/import` עם מערך JSON תחת Basic Auth. המערכת תסנן רשומות לפי מחיר, יישוב וסוג נכס. ב־`POST /api/scan` מופעל יבוא ידני של הקבצים; מתזמן יוכל לייבא מדי יום.

הנכסים שמסומנים כמוסתרים נשארים במאגר, ולא יוצגו שוב גם אם יופיעו במקור מדי יום. ההערות והמועדפים נשמרים עם המזהה הקבוע `(source,source_id)`.

## דואר יומי

מגדירים `SITE_URL` (כתובת HTTPS אמיתית של האתר) ואת SMTP_HOST / SMTP_PORT / SMTP_USER / SMTP_PASSWORD / SMTP_FROM. אם משתמשים ב־Gmail, יש צורך בגישה מורשית למשל App Password אם החשבון תומך בכך; לא משתמשים בסיסמת Gmail רגילה. הפרטים נמצאים ב־`.env.example` (הקובץ להמחשה בלבד; יש לטעון משתני סביבה באמצעי האירוח).

עם `ENABLE_SCHEDULER=1`, כל יום לפי Asia/Jerusalem: 07:30 ביצוע יבוא, ומ־08:00 שליחת תקציר עבור **היום הקודם** ל־amir.cog@gmail.com ול־revital.kedemtal@gmail.com. תקציר נשלח גם ביום עם 0 בתים חדשים. כדי למנוע מייל כפול, נשמר רישום לפי יום; אם המייל נכשל, תתבצע שוב בדיקה לאחר דקה. תהליך חייב לרוץ ברציפות — אירוח serverless ישן לא מתאים. יש להריץ מופע אחד בלבד של הסקד׳ולר ומופע Uvicorn אחד (או להשתמש ב־cron חיצוני ולבטל את הסקד׳ולר).

## פריסה

יש צורך בשרת Python זמין 24/7 עם אחסון SQLite מתמשך, דומיין/HTTPS, סוד APP_PASSWORD, פרטי SMTP והרשאה למקור נתונים. מאחר שהאתר מכיל הערות פרטיות, אין להעלות אותו ללא הגנת סיסמה ו־HTTPS. בתצורת PaaS מקובל להגדיר שירות Python יחיד עם פקודה `uvicorn app:app --host 0.0.0.0 --port $PORT`, volume מתמשך ל־DB_PATH, ומשתני הסביבה. אין להריץ כמה workers כאשר `ENABLE_SCHEDULER=1`.
